HOW IT WORKS IN PRACTICE

NORMAL DAY (Moderation + Backups):
  ├─ Jelly Guardian + Backup Bot running 24/7
  ├─ Monitoring violations in real-time
  ├─ Deleting rule violations (if not in shadow mode)
  ├─ Logging everything to deletion-log.jsonl
  ├─ At 2 AM: Automatic daily backup runs
  ├─ Backup saved to data/backups/
  └─ Dashboard shows real-time decisions

DISASTER STRIKES (Server Destroyed):
  ├─ Jelly Guardian + Backup Bot continues running (safe)
  ├─ You get latest backup from /getbackup
  ├─ Click saved Restore Bot OAuth2 invite link
  ├─ Restore Bot joins server (first time ever invited)
  ├─ You run: /loadbackup (upload backup file)
  ├─ You run: /restore (restores everything)
  ├─ After restore completes: Remove Restore Bot
  ├─ Restore Bot goes offline (back to default state)
  └─ Server is recovered! 🎉

SECURITY MODEL

If Jelly Guardian Token Stolen:
  → Attacker can delete messages (caught by rate limiter)
  → Restore Bot is safe (offline, no token)
  → Recovery: Regenerate token (5 min)

If Restore Bot Invite Link Discovered:
  → Attacker clicks link (bot joins server)
  → Admin immediately removes it
  → No token = no sustained attack
  → No damage possible

If Lightsail SSH Compromised:
  → .env contains: ONE token (Jelly Guardian)
  → .env does NOT contain: Restore Bot token
  → Attacker gets one token, not zero
  → Recovery: Regenerate token (5 min)

Result: Maximum safety, minimal complexity ✅
